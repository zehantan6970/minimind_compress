# Knowledge Distillation (MoE Teacher → Dense Student)

This folder contains the full knowledge-distillation pipeline for MiniMind-O:
**teacher `minimind-3o-moe` (MoE, 315M, frozen) → student `minimind-3o` (Dense, 113M, trainable)**.

> 中文说明见根目录 [readme_cn.md](../readme_cn.md)。A one-page English tutorial is in [docs/distillation/logit_distillation_explained.html](../docs/distillation/logit_distillation_explained.html).

## Scripts

| Script | Purpose |
|---|---|
| `kd_common.py` | Shared utilities: load a model, greedy text generation, read prompts |
| `kd_teacher_generate.py` | Teacher answers a batch of prompts offline (sequence-level); resume + quality filtering |
| `kd_make_synthetic.py` | Generate template hard-label data (15 intents, paraphrased prompts × fixed short replies) |
| `kd_train_student.py` | Student plain-text SFT (hard labels); only updates Thinker |
| `kd_train_logit.py` | Logit-level soft-label KD (teacher online, KL + CE) |
| `kd_eval.py` | Early eval: similarity to the teacher |
| `kd_eval_intent.py` | **Recommended** eval: intent accuracy via substring keyword rules |
| `kd_dump_logits.py` | Real 6400-dim distribution diagnostic at a given position |
| `kd_infer.py` | Deployment inference: load only the student, single / interactive, greedy |

## Workflow

```bash
# 1. Generate the 211 template examples
python kd_make_synthetic.py --out kd_sft_lamp.jsonl

# 2a. Hard-label SFT (best command-domain model)
python kd_train_student.py --student_dir ./minimind-3o --data kd_sft_lamp.jsonl --out_dir ./kd_dense_lamp2 --epochs 3 --batch_size 8 --lr 1e-4 --max_seq_len 384 --device cuda

# 2b. Logit-level soft-label KD
python kd_train_logit.py --teacher_dir ./minimind-3o-moe --student_dir ./minimind-3o --data kd_sft_lamp.jsonl --out_dir ./kd_dense_logit --epochs 3 --batch_size 4 --temperature 4.0 --alpha 0.3 --device cuda

# 3. Evaluate intent accuracy
python kd_eval_intent.py --base_dir ./minimind-3o --student_dir ./kd_dense_lamp2 --prompts kd_eval_intents.jsonl --max_new_tokens 128 --device cuda

# 4. (optional) 6400-dim diagnostic
python kd_dump_logits.py --teacher_dir ./minimind-3o-moe --base_dir ./minimind-3o --student_dir ./kd_dense_logit --prompt "Turn on the light." --answer "Sure, I'll turn on the light." --target_word on --temperature 4.0 --device cuda

# 5. Deploy
python kd_infer.py --model_dir ./kd_dense_lamp2 --prompt "Turn on the light." --device cuda
```

You can also use the root launcher: `python ../main.py make-data | train-hard | train-logit | eval | dump | infer`.

## Results (real numbers)

| Approach | Data | Intent accuracy |
|---|---|---|
| Untrained base | — | 22.6% |
| Hard labels | 98 | 56.6% |
| **Hard labels (final)** | **211** | **75.5%** |
| Logit soft (T=4, α=0.3) | 211 | 64.2% |

Per-position KL (T=4) drops after KD: on 0.2774 → 0.1017; thanks 0.3240 → 0.1779; joke 0.4058 → 0.2598.

## Key conclusion

**Hard for commands, soft for chat.** Deterministic commands are best with hard labels (75.5%, α≈0), because the teacher hedges on commands during free generation. Open chat / jokes are better with soft labels (α≈0.7). Always evaluate the teacher on your task before trusting its soft targets.
